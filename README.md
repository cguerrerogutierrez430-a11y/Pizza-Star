# Pizza Star

Videojuego 3D en HTML (Three.js) con 3 niveles: picar, preparar y hornear la pizza.

- `index.html`: el juego completo (carátula + menú + 3 niveles). Ya lleva los modelos 3D y el logo dentro, así que funciona solo.
- `logo.png`: tu logo con fondo transparente (respaldo).
- `modelos/`: copia de los archivos .glb originales (respaldo para seguir editando en Blender). El juego NO los carga desde aquí.

Controles: flechas o A/D mover, E acción, Q (o F/Shift) brazo/limpiadora, P pausa.
Necesita internet para cargar la librería three.js desde jsDelivr.
